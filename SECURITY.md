# Security policy

## Supported versions

This project is currently maintained on the latest revision of the default branch. Older commits and unreleased local modifications are not supported separately.

## Reporting a vulnerability

Do not disclose security vulnerabilities in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/timtwiest/simple-java-api/security/advisories/new) and include:

- the affected endpoint or component;
- steps to reproduce the problem;
- the potential impact;
- any suggested mitigation, if available.

Please remove credentials, access tokens, personal data, and unrelated production information from the report. You should receive an initial response within seven days. A fix and disclosure timeline will be coordinated after the report is validated.
